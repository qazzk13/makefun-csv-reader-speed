A fast drop-in for make.fun's csv-reader 1.0.0: it reads broken CSV files
exactly as the reference does — BOM, LF/CRLF line breaks, stray CRs,
quoted fields with doubled quotes and line breaks inside them, junk after
a closing quote, unterminated quotes, short and long rows — and answers
`{columns, rows, errors}` for every case, several times faster than the
reference. `solve.js` is a dependency-free ES module whose `run(input)`
returns csv-reader's answer; `main.ts` is the program the harness runs,
reading `/input/cases.json` and writing `/output/answers.json`.

## Run it

```sh
MAKEFUN_INPUT_DIR=./input MAKEFUN_OUTPUT_DIR=./output node main.ts
```
